# Shenanigans

[![](img/shenanigansLogo.png){.center}](https://modrinth.com/modpack/shenanigans)

Shenanigans is a Minecraft modpack with new biomes, structures, food, building options, and changes to familiar gameplay.

Get the released pack from [Modrinth](https://modrinth.com/modpack/shenanigans) or [CurseForge](https://www.curseforge.com/minecraft/modpacks/shenanigans-cf-edition). The [GitHub repository](https://github.com/Syrup-Studios/shenanigans) contains the source code.

Start with [Getting started](getting_started.md) for install, update, and support information.
