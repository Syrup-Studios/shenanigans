# Storage & Logistics

Storage options include Sophisticated Backpacks, Sophisticated Storage, Storage Drawers, and Tom's Simple Storage Mod. Create trains and Via Romana add transport options.

## Backpacks

Backpack capacity and upgrade slots depend on the material:

| Backpack | Storage slots | Upgrade slots |
| --- | ---: | ---: |
| Leather | 27 | 1 |
| Copper | 45 | 1 |
| Iron | 54 | 2 |
| Gold | 81 | 3 |
| Diamond | 108 | 5 |
| Netherite | 120 | 7 |

The Magnet Upgrade picks up items within 3 blocks. The Advanced Magnet Upgrade reaches 5 blocks. Both have filter slots.
