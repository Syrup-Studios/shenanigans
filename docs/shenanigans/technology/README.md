# Technology

Create provides machinery and transport. Add-ons include Threaded Trains, Create Aeronautics, and Steam 'n' Rails.

Use Create filling with 250 mB of water to advance supported copper items by one oxidation stage.

Create crushing processes Meadow alpine ores and Nature's Spirit chert ores into crushed metals or rough gems. Some recipes also give experience nuggets or local stone. Their copper ore recipes each give five crushed raw copper, with a 25% chance of one extra.

See [recipe changes](../changes/recipes.md) for smelting times and other recipes.
