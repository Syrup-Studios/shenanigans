# Getting started

## Install the pack

1. Choose a release on [Modrinth](https://modrinth.com/modpack/shenanigans) or [CurseForge](https://www.curseforge.com/minecraft/modpacks/shenanigans-cf-edition).
2. Install the complete pack with a launcher that supports that platform. Do not install individual mod files.

## Recipes and controls

The pack includes EMI for in-game recipe lookup. For recipes added or changed by Shenanigans, see [recipe changes](changes/recipes.md).

To check available key bindings, open Minecraft's **Options → Controls** menu.

## Update an existing world

Back up the world and instance before you update. Pack updates can change gameplay. New biomes and structures usually appear in newly generated chunks. Explore new areas to find them. Check the release notes before you update.

## Play with other people

Use the same Shenanigans release as the host.

## Report a problem

Include the pack release, what you did, and the error message. If you share a log or crash report, remove private information first. Report problems through [GitHub Issues](https://github.com/Syrup-Studios/shenanigans/issues) or the [community Discord](https://discord.gg/RPEz5JX4EM).
