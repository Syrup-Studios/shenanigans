# Exploration

The pack includes biome mods, Repurposed Structures, Explorer's Compass, Nature's Compass, and Camerapture.

Maps can show landmarks. Click a beacon, lodestone, respawn anchor, bed, conduit, or portal with a map to mark it. A death marker appears on your map when you die with a Recovery Compass in your inventory.

Bundled structure datapacks contain:

| Datapack | Structures |
| --- | --- |
| ATi Structures | Temples, castles, forts, and keeps. |
| Epic Dungeons | Small, medium, and large dungeons, with ice, plains, and sand variants. |
| Epic Villages | Structure pieces for plains, snowy, and taiga villages. |
| Epic Witch Huts | Witch huts and added sections. |
| Epic Igloos | Small and large igloos. |
| Tidal | Ocean village structures. |

Generation depends on the active datapacks and the world.

Plushies are in loot tables for woodland mansion, Nether fortress, End city, bastion, and shipwreck chests.
