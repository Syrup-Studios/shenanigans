# Magic

Arcane lantern tooltips describe these effects:

| Lantern | Effect |
| --- | --- |
| Life | Speeds up nearby crop growth. |
| Feral | Spawns sparks to light a large area. The lantern vanishes after it has lit the area and spawned enough sparks. |
| Love | Makes nearby mobs fall in love. |
| Wailing | Cries when you get close. It screams and causes nausea when you get closer. |
| Boreal | Slows nearby mobs and players. It also puts out burning mobs. |
| Brilliant | Turns nearby animals into experience. |
| Warding | Pushes living entities away, except players. |
| Containing | Keeps living entities in an area, except the player. |
| Withering | Applies the Wither effect nearby. |
| Cloud | Applies Slow Falling nearby. |
