Shenanigans is a Minecraft modpack with new biomes, structures, food, building options, and changes to familiar gameplay.

Install a release from [Modrinth](https://modrinth.com/modpack/shenanigans) or [CurseForge](https://www.curseforge.com/minecraft/modpacks/shenanigans-cf-edition). Start with the [getting started guide](docs/shenanigans/getting_started.md).
