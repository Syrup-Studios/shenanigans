## Changelog 0.12.0

### Added
- Added Envelope.
- Added Ars Elixirum.
- Added fishing advancements and Traveller's Handbook entries for getting a rod, catching a first fish, fishing in rivers, and catching cod, salmon, tropical fish, pufferfish, koi, bass, catfish, anglerfish, blobfish, piranha, and ray. Also added entries for catching a great white shark and a live tropical fish.
- Added gardening, cooking, magic, exploration, and structure advancements and Traveller's Handbook entries.

### Changed
- Removed vanilla chests and barrels. Recipes that use chests or barrels now accept items in the matching chest or barrel tag.
- Added Sophisticated Storage recipes for 11 wood types and generic wood recipes.
- Set the default GUI scale to 3 and set the Spyglass Improvements key binding to C.
- Switched to Obscure Tooltips.
- Copper tools and armor now use Vanilla Backport items under the same item IDs, replacing the custom KubeJS items.
- More Axolotl Variants API changed from Fabric 1.3.0 to NeoForge 2.4.0+1.21.1.
- More Axolotl Variants changed from Fabric 1.3.1 to NeoForge 2.2.0+1.21.1.
- Spyglass Improvements now runs on both the client and server.
